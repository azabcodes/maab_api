# Arabic TTS Voice Model (Kareem low)

Offline neural text-to-speech voice model for the Maab app (Piper VITS architecture, Jordan Arabic dialect, Kareem voice).
Downloaded by the app on first use to read Tafsir, Hadith, and Islamic books offline.

- Architecture: VITS (Piper)
- Model: ar_JO-kareem-low.onnx (~60.3 MB)
- Tokens: tokens.txt
- Phonemizer Data: espeak-ng-data.tar.bz2 (~6.9 MB)
- Source: https://huggingface.co/csukuangfj/vits-piper-ar_JO-kareem-low
- Framework: sherpa-onnx / Piper
